# Detect Bimodal Distribution (BD) Genes (Bimodal Separation Index)

Detect Bimodal Distribution (BD) Genes (Bimodal Separation Index)

## Usage

``` r
calc_signal_bd(exprs_mat, cell_types)
```

## Arguments

- exprs_mat:

  Matrix (genes x cells).

- cell_types:

  Factor of 2 cell types.

## Value

Numeric vector of Bimodality Index values.
