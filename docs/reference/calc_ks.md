# Calculate Kolmogorov-Smirnov Distance (1D KS)

Calculate Kolmogorov-Smirnov Distance (1D KS)

## Usage

``` r
calc_ks(ref, sim)
```

## Arguments

- ref:

  Numeric vector of reference values.

- sim:

  Numeric vector of simulated values.

## Value

Maximum vertical distance between empirical CDFs (between 0 and 1).
